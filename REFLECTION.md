When I type my website address into a browser, the browser sends a request to find my website. First, the browser uses DNS to find where the website is located. After finding the GitHub Pages server, the request goes to GitHub and asks for the files that make up my website. GitHub then sends back the files, such as my HTML file, CSS file, and images. The browser reads these files and uses them to display my website.
